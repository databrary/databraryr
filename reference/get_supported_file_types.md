# Extracts File Types Supported by Databrary.

Extracts File Types Supported by Databrary.

## Usage

``` r
get_supported_file_types(vb = options::opt("vb"))
```

## Arguments

- vb:

  Show verbose messages. (Defaults to `FALSE`, overwritable using option
  'databraryr.vb' or environment variable 'R_DATABRARYR_VB')

## Value

A data frame with the file types permitted on Databrary.

## Examples

``` r
if (FALSE) { # \dontrun{
get_supported_file_types()
} # }
```
