# Log Out of Databrary.org.

Log Out of Databrary.org.

## Usage

``` r
logout_db(vb = options::opt("vb"))
```

## Arguments

- vb:

  Show verbose feedback. Defaults to `options::opt("vb")`.

## Value

TRUE if logging out succeeds, FALSE otherwise.

## Examples

``` r
# \donttest{
logout_db()
#> [1] TRUE
# }
```
