# Check SSL Certificates For nyu.databary.org.

`check_ssl_certs` checks the SSL certificates for nyu.databrary.org and
returns a data frame with the relevant information.

## Usage

``` r
check_ssl_certs(host = "nyu.databrary.org")
```

## Arguments

- host:

  Target URL. Defaults to 'nyu.databrary.org'.

## Value

A data frame with information about the SSL certificates.

## Examples

``` r
if (FALSE) { # \dontrun{
check_ssl_certs()
} # }
```
